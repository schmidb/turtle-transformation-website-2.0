# Tech and deployment

- Astro 5 static site, Tailwind CSS 3, Node.js 22. Install with `npm ci`.
- Always verify changes with `USE_CUSTOM_DOMAIN=true npm run build` (PowerShell: `$env:USE_CUSTOM_DOMAIN="true"; npm run build`). Without the flag the build uses the github.io base path.
- Do not run `npm run preview` at the same time as a build.
- Deployment: pushing to `main` triggers `.github/workflows/deploy.yml` (GitHub Pages). The repo variable `USE_CUSTOM_DOMAIN` must remain `true`.
- Use `getRelativePath()` from `src/utils/paths.ts` for internal links and assets.
- Canonical URLs, sitemap and Open Graph tags point to `https://turtletrafo.com` (`src/layouts/Layout.astro`, `src/utils/schema.ts`).
- The sitemap is generated by `@astrojs/sitemap`. There is no hand-written `sitemap.xml`.
- Structured data is centralised in `src/utils/schema.ts` (Organization, WebSite, Person, WebPage, Breadcrumb, FAQ). Visible FAQ text and FAQ schema must come from the same data (`Faq.astro` plus `faqPageSchema`).
- Fonts are self-hosted via `@fontsource-variable/*`. Do not add Google Fonts or other third-party requests on page load.
- Pin new dependencies to exact versions.
- Mobile first: no horizontal overflow at 390px, tap targets at least 44px.
- Infrastructure (DNS, CloudFront, ACM, GitHub Pages, GHL) is documented in `docs/infrastructure.md`. Do not change it unless asked.
